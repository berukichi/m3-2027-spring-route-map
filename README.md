# M3春2027 巡回マップ

M3-2027春（2027年4月25日(日) 10:30〜・東京流通センター）で回りたいブースを会場マップに配置し、優先順位に合わせた巡回ルートを表示するスマホ向けページです。

> **準備中：** M3春2027の出展者・会場配置はまだ発表されていません。発表までは、M3秋2026のサークル一覧と会場マップを仮に使っています。M3秋2026版は [m3-2026-autumn-route-map](https://berukichi.github.io/m3-2026-autumn-route-map/) にあります。

| ページ | 内容 |
|---|---|
| [`index.html`](./index.html) | ブランク版。ブースは入っていません。ブース番号を入力して自分のリストを作れます。 |
| [`my/index.html`](./my/index.html) | 18ブース入り版（M3秋2026で使ったリストを仮に入れています）。M3 Webカタログのサークル一覧を内蔵していて、サークル名・よみ・Xのアカウント名でも検索して追加できます。 |
| [`help.html`](./help.html) | 使い方（マニュアル）。各ページ右上の本のアイコンと、ページ下のリンクから開けます。 |

## 機能

- 第一展示場（2F）・第二展示場1F・2Fの3つの地図を切り替え、ブースに巡回順の番号を表示
- 優先順位をドラッグ（またはキーボードの↑↓）で並べ替え。「優先順位を並べ替える」ボタン（またはURL末尾の `#rank`）で開くポップアップで操作
  - 初期設定は「フロアごと」。第一展示場・第二展示場1F・第二展示場2Fを別々に並べ、1つのフロアを回り終えてから次のフロアへ移る（フロアの順番は歩く距離が短くなるよう自動で決定）
  - 「まとめて」にすると全ブースを1つのリストで並べる（建物の行き来が増えることがある）
  - 「最短距離」で「後回し」をオフにしたときは、1位以外の順位を使わない（画面に案内を表示）
- ルートは3種類
  - 最短距離（初期設定）: 優先順位1位のブースから回り始め、そこから最短の順に回る。初期設定では上位5位までを先に回り、6位以下はそのあとに回る（「後回し」の設定でオフにしたり、何位までを先に回るかを変えたりできる）
  - 近くを寄り道: 上位3件の中から近いブースを先に回る。どのブースも本来の順位から2つより後ろには下がらない
  - 優先順位どおり
- 第一展示場は入口と出口が別。第二展示場へは北側の出口から出る。開場直後は南入口からのみ入場でき、「午後」に切り替えると北入口も使うルートを計算
- 第二展示場1Fも入口と出口が別（出口は東側の入口のすぐ北側）。開場直後は1F西側の待機列から南西の入口へ入り、午後は東側の入口を使うルートを計算
- 同じ机や隣の机のブースは、先に回るブースの番号を大きく、あとのブースの番号を小さく横に表示
- 訪問済み・パスにすると、地図が次のブースへ移動し「次 ▸ サークル名（ブース番号）」を表示
- 「パス」したブースはルートの最後に回り、地図にも残る（取り消し可）
- 右上のボタンでライト／ダーク表示を切り替え（ブラウザに記憶。未設定なら端末の設定に従う）
- パレットのボタンから配色テーマを10種類から選択（ブラウザに記憶。ライト／ダークどちらにも対応）
- 地図の「固定」ボタンで、地図を画面上部に固定したままルートのリストをスクロールできる（初期設定はオン）
- 設定はルートの種類を大きなタブで切り替え、スタート地点と時間帯は「スタート・時間帯」を開いて変更
- 「ほかの端末と共有」で、ブース・優先順位・訪問済み・ルート設定をほかの端末へ写せる（QRコード・共有URL・共有コード。その時点の内容を写す方式で、自動同期はしない）
- 訪問済みチェックでルートを再計算
- 戦利品カメラ（設定でオン）：各ブースのカメラのボタンで訪問済みにして撮影し、写真を保存したり、共有メニューからXのアプリに写真付きで渡したりできる。X APIは使わず、投稿はXのアプリで行う。写真は端末の外に送らず、長い辺2048pxに作り直す（撮影場所の情報は残らない）
- ホーム画面に追加してアプリのように使える（`manifest.webmanifest`・アイコン・`sw.js`）。一度開けば電波が弱くても前回の内容で表示する。iPhoneのホーム画面のアプリはSafariとデータが別なので、「ほかの端末と共有」で写す
- ブース番号（例: `コ-21b`、`T-15ab`、`ク-10x`）でブースを追加、「外す」で削除。ク-03〜36・ケ-03〜07 は a/b ではなく x/y/z で3つに分かれている

## データの保存

優先順位・訪問済み・追加したブースは、各端末のブラウザの localStorage に保存されます。Cookie は使っておらず、サーバーにも送信しません。そのため、複数の人が使ってもデータが混ざったり上書きされたりすることはありません。

PCとスマホなどで同じリストを使うときは「ほかの端末と共有」を使います。送る側に表示されるQRコードを読み取るか、共有URL・共有コードを受け取る側で開くと、確認のあとで内容が置き換わります。データはURLの `#` 以降に入るだけで、サーバーには送られません。

- ブランク版と18ブース入り版は別々のキーに保存されます。
- 同じブラウザで複数のタブを開いた場合は、最後に保存した内容がほかのタブにも反映されます（古いタブで上書きしないようにしています）。
- ブラウザのサイトデータを消去すると、保存内容も消えます。
